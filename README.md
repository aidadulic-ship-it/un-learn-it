# UN-LEARN IT

Statische Webseite für GitHub Pages (Ordner direkt hochladen, Pages auf den Hauptzweig stellen).

- /grillme baut Prompts für die eigene KI der Besucher:innen. Es gibt keinen Server und keinen API-Schlüssel.
- Figuren: Sophie, Markus, Lea und Tim (Bilder `sophie.jpg` usw.). Die Rechte an den Bildern sind vor der Veröffentlichung zu klären; Ersatzbilder unter gleichem Namen ablegen.
- Noch einzutragen: Termine, Orte, Preise, E-Mail, Impressum, Kurzprofile, Zitate, Konditionen (in der Seite als [eckige Klammern] markiert).
- Vor dem Livegang: Datenschutz und EU AI Act prüfen und die Prompts in ChatGPT, Claude und Gemini testen.
